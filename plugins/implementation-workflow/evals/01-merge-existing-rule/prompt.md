まず、作業ディレクトリに `AGENTS.md` を以下の内容ちょうどで作成してください。

```
# エージェント向け指示

このリポジトリは pnpm workspace で、`web` と `api` の 2 パッケージを持つ。

## 実装ルール
- 新しい依存を追加する前に、既存の依存で解決できないか確認する。
- 型に `any` を使わない。やむを得ない場合は理由をコメントに残す。
- 共通ロジックは `packages/shared` に置く。web/api 側に複製しない。

## 検証
- 変更後は `pnpm test` を実行する。
- test が落ちたまま完了報告しない。
- スナップショットを更新したときは差分を目視してから進む。

## commit 前チェック
- commit メッセージには変更の理由を書く。何をしたかは diff を見れば分かる。
- 生成物やログファイルを commit に含めない。

## PR 作成
- PR の説明には動作確認した手順を書く。
- CI が緑になるまで review を依頼しない。

## 報告
- 変更したファイルと理由を簡潔に述べる。
- 未検証の項目があれば明示する。
```

作成できたら、次の指摘に対応してください。

さっき typecheck を回さずに完了報告したよね。commit 前に typecheck も必ず回して。次から徹底して。
