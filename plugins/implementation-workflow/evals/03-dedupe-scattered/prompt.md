まず、作業ディレクトリに `AGENTS.md` を以下の内容ちょうどで作成してください。

```
# エージェント向け指示

このリポジトリは pnpm workspace で、`web` と `api` の 2 パッケージを持つ。

## 実装ルール
- 型に `any` を使わない。
- 実装を変えたら `pnpm test` を回してから次へ進む。
- 共通ロジックは `packages/shared` に置く。

## 検証
- 変更後は `pnpm test` を実行する。
- lint は `pnpm lint` で実行する。
- 落ちたまま完了報告しない。

## commit 前チェック
- 生成物やログファイルを commit に含めない。
- commit の前に `pnpm test` が通っていることを確認する。

## PR 作成
- PR を出す前に `pnpm test` が通っていることを確認する。
- PR の説明には動作確認した手順を書く。

## トラブルシュート
- test が遅いときは対象パッケージを絞って実行する。

## 報告
- 変更したファイルと理由を簡潔に述べる。
```

作成できたら、次の指摘に対応してください。

また test の実行方法を間違えてる。同じことが何箇所にも書いてあってどれを読めばいいか分からない。記述を統一して、二度と間違えないようにして。
